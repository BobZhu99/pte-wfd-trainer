针对 PTE Academic 核心高分题型与考生薄弱环节量身打造的沉浸式实战备考套件。

### 🌟 在线入口
- 🎯 **[WFD 极速听写打卡训练器](https://bobzhu99.github.io/pte-wfd-trainer/)**
- 🎤 **[120~140 WPM 口语卡拉OK导引器 (RA / RS / DI)](https://bobzhu99.github.io/pte-wfd-trainer/speaking_karaoke.html)**

### 功能亮点
1. **口语 120~140 WPM 卡拉OK导引器 (RA / RS / DI)**：
   - 🎯 **黄金巡航语速控制**：110~150 WPM 自由调节，默认为 Versant 声学评分引擎最佳识别语速 130 WPM。
   - 🫁 **智能换气呼吸阀**：逗号/分号停顿 0.25s 提示吸气，句号停顿 0.35s 提示换句，彻底告别不当停顿扣分。
   - 🎧 **考场原声多口音跟读**：RS 包含全套考场原声 MP3（女声/男声/挑战口音），支持「先听再复述」考场实操模式与「原声同步共读」卡拉OK模式。
   - 📊 **DI 25秒黄金四段打卡**：四段式时间胶囊（0-6s 开头、6-12s 关键点一、12-18s 关键点二三、18-24s 总结），拒绝 15 秒提前闭嘴或超时。
   - 🎙️ **麦克风录音即时回放**：边看提词跟读边录音，读完自动秒出回放试听对比。

2. **WFD 极速听写打卡训练器**：
   - 🎧 **考场原声 MP3**：真题多口音原声音频，支持 0.9x ~ 1.2x 变速播放与音源切换。
   - 🎯 **官方同源评分算法**：一词一分，精准识别考场试词（单复数/时态试词安全防漏）。
   - 📕 **错题深度诊断本**：自动沉淀历史答题档案，生成趋势对比与错因诊断，支持一键重做攻克。
   - 📱 **移动端离线体验**：自适应 iPhone / Safari / Android，支持添加到主屏幕 PWA 式畅快刷题。

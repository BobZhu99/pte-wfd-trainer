📅 每周三周预测自动化更新指南
  1. 获取最新预测 PDF：每周三萤火虫发布新版周预测后，下载 PDF 文件并放入电脑本地 PTE备考 文件夹。
  2. 一键提取并更新题库：在终端执行： 
    python sync_weekly_prediction.py
    或双击运行 run_daily_sync.bat。脚本会自动从 PDF 提取最新 WFD 题目并比对变动。
  3. 一键编译网页与发布： 
    python build_wfd_web.py
    重新编译后，自动推送到 GitHub 仓库。
  4. 多设备无缝同步：手机、iPad 或任意其他设备打开本网页，点击【更新题库】→【云端自动拉取】，即可秒级更新至最新真题库！
